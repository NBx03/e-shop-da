# «ДА!» — Интернет-магазин электроники в Telegram Mini App и Браузере (ООО «ДА»)

Полнофункциональный интернет-магазин электроники и бытовой техники, работающий одновременно как **Telegram Mini App** и как **полноценный адаптивный веб-сайт** в браузере (desktop & mobile).

---

## 🚀 Стек технологий

- **Backend:** Python 3.11, Django 5.1, Django ORM
- **Database:** PostgreSQL 15 (поддерживается автоматический fallback на SQLite в локальном окружении)
- **Telegram Bot & Mini App:** Aiogram 3.x, Telegram WebApp JS SDK
- **Безопасность:** Криптографическая валидация `initData` по алгоритму HMAC-SHA256 (с проверкой подлинности `hash` и срока `auth_date`)
- **Медиа:** Автоматическое сжатие и конвертация изображений в WebP (Pillow)
- **Frontend:** HTML5, Tailwind CSS, Lucide Icons, vanilla JS (адаптивная мобильная верстка, поддержка Telegram CSS Variables светлой/темной темы, localStorage)
- **Инфраструктура:** Docker, Docker Compose

## 📦 Быстрый запуск

### Вариант 1. Через Docker Compose (Рекомендуемый)

1. Склонируйте репозиторий и создайте файл окружения:
   ```bash
   cp .env.example .env
   ```
2. В файле `.env` укажите ваш `BOT_TOKEN` (полученный у [@BotFather](https://t.me/BotFather)) и ID чата для уведомлений магазина `TELEGRAM_ADMIN_CHAT_ID`.
3. Запустите контейнеры:
   ```bash
   docker compose up --build
   ```
   *Все миграции и 25 тестовых товаров со статусами и WebP-изображениями загрузятся автоматически!*

4. Создайте суперпользователя для входа в панель управления:
   ```bash
   docker compose exec web python manage.py createsuperuser
   ```

Магазин доступен по адресу: [http://localhost:8000](http://localhost:8000)  
Админ-панель: [http://localhost:8000/admin/](http://localhost:8000/admin/)

---

### Вариант 2. Локальный запуск без Docker

```bash
# 1. Создание и активация виртуального окружения
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Применение миграций и наполнение 25 тестовыми товарами
python manage.py migrate
python manage.py seed_data

# 4. Запуск локального сервера
python manage.py runserver
```

## 📱 Подключение к Telegram (Mini App)

Telegram Mini App требует HTTPS соединения. Для локального тестирования поднимите туннель:

1. **Запустите ngrok или localtunnel:**
   ```bash
   ngrok http 8000
   ```
   Скопируйте полученный HTTPS адрес (например, `https://abcdef.ngrok-free.app`).

2. **Внесите URL в `.env`:**
   ```env
   WEBAPP_URL=https://abcdef.ngrok-free.app
   ```

3. **Настройте кнопку бота у [@BotFather](https://t.me/BotFather):**
   - Отправьте `/mybots` -> выберите вашего бота.
   - Выберите `Bot Settings` -> `Menu Button` -> `Configure menu button`.
   - Отправьте ссылку на ваш WebApp: `https://abcdef.ngrok-free.app`.

4. **Запустите бота:**
   ```bash
   python manage.py run_bot
   ```

## 🎯 Ключевые возможности и реализация ТЗ

### 1. Каталог товаров
- Единый адаптивный интерфейс для браузера и Telegram.
- Разделы: Смартфоны, Ноутбуки, Наушники, Планшеты, Умный дом.
- Сортировка по цене, живой поиск с debounce.
- Статусы: **«В наличии»** (зеленый), **«В пути»** (оранжевый), **«Под заказ»** (индиго).
- Для товаров «Под заказ» доступна кнопка **«Хочу такой»**: заявка с контактами сохраняется в БД, админ видит число заявок и уведомление в Telegram.

### 2. Прямые ссылки на товар (startapp)
- Ссылка формата `https://t.me/<bot_username>?startapp=<slug>` открывает Mini App сразу на карточке конкретного товара.

### 3. Корзина и оформление
- Корзина сохраняется в `localStorage` и не сбрасывается при закрытии WebApp.
- Способы получения: Самовывоз, Курьер по городу, Отправка в регионы.
- **Бизнес-правило:** при отправке в регионы доступна только онлайн-оплата (оплата при получении блокируется).

### 4. Оплата заглушкой (Эмуляция банка)
- Страница `/orders/payment/mock/<id>/` с кнопками «Оплата прошла» и «Отказ».
- Отправляет вебхук на `/orders/payment/webhook/` по тому же контракту, что и реальный платежный шлюз.
- При успешной оплате заказ переводится в статус `paid`, бот отправляет уведомление магазину и покупателю.

### 5. Django Admin (с фокусом на мобильные устройства)
- Наглядные бейджи статусов заказов и оплат.
- Счетчик заявок «Хочу такой» по каждому товару.
- **Автоматическая отправка трек-номера:** при внесении `tracking_number` сигнал Django автоматически отправляет покупателю сообщение в Telegram с номером посылки.

### 6. Безопасность (HMAC-SHA256)
- Подпись `initData` валидируется на бэкенде через алгоритм Telegram:
  `HMAC_SHA256("WebAppData", bot_token)`.
- Попытки подделки `user_id` или устаревшие сессии пресекаются ответом `403 Forbidden`.
